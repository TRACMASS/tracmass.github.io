Introduction

In this chapter we will take a closer look at how trajectory seeding (initilization) is done in TRACMASS. Two types of seeding are possible - from boxes defined in the namelist file and from seeding files. It is recomended to first try out seeding from the namelist file, to get an idea of how it works, before starting with the seeding files.

In these example we will be considering a case where only a single trajectory is initilized from each grid-cell (nqua=1 and partquant=1) and only the trajectories with positive flux (idir=1), forward in time (nff=1), and on meridional (isec=2) grid cell's face.

File seed_condition.txt

The seeding file contains sets up the seeding condition with three parts:

  • 1st, 2nd, 3rd column - grid cell's location in the form of model index in x, y, and z direction
  • 4th collumn - which grid wall is used for seeding (isec)
  • 5th column - flux direction (idir)

File seed_time.txt

For the time file, there is only one column present and it determines in which global iterations (intrun) seeding should take place. The time steps need to be organized in a column, similarly to the seeding condition input file.

Number of Trajectories

In this subchapter, a closer look at initilizing different number of trajectories is considered. In general there are 3 types:

  • nqua=1: constant number in particles in all seeding cells
  • nqua=2: Proportional to the mass/volune transport at seeding
  • nqua=3: Proportional to mass/volume in the seeding cell

nqua=1

As the description states, with this method a constant number of particles are seeded at every defined grid cell's face. In this example, we seed 10 trajectories and we present a namelist snippet containing only the variables that are needed for this setup.

{{ site.data.tutorial_examples.seed_type_constant_number }}

nqua=2

In this case, the number of particles in a grid cell is defined with the volume/mass transport throught the face and the volume/mass that is defined to represent a single trajectory. For example, if total volume transport is 10 m3/s and partQuant=5, we get subvol/partQuant=2 trajectory seeding locations in that grid cell.

{{ site.data.tutorial_examples.seed_type_prop_mass_trans }}

nqua=3

For nqua=3 case, the cell's volume/mass is used for calculating the number of seeding points, by using a constant parQuant value for each trajectory's seeding point. In this example, we set partQuant=0.1, which states that each trajectory will represent 0.1 m3 of volume of the starting grid cell. If we have a grid cell with the volume 1 m3, then we will have seeded 10 trajectories in the grid cell.
